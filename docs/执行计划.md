## 阶段三：GitHub Actions 打包 EXE

### 仓库准备

1. 在 GitHub 创建仓库（可设为 Private）
2. 将项目整个文件夹推送：

```bash
cd /path/to/20260510_银行流水报表系统
git init
git add .
git commit -m "feat: 资金统计软件 v2.1 GUI 版"
git remote add origin https://github.com/<你的账号>/<仓库名>.git
git push -u origin main
```

### GitHub Actions 工作流

创建 `.github/workflows/build.yml`：

```yaml
name: Build Windows EXE

on:
  push:
    tags:
      - 'v*'

jobs:
  build:
    runs-on: windows-latest

    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install dependencies
        run: |
          pip install customtkinter pillow openpyxl xlrd pyinstaller

      - name: Build EXE
        run: |
          pyinstaller --onefile --windowed `
            --name "资金统计软件" `
            --add-data "assets;assets" `
            --add-data "src/生成报表.py;." `
            --add-data "src/修正补录.py;." `
            --add-data "src/_核心库.py;." `
            --icon "assets/logo.ico" `
            src/界面.py

      - name: Upload EXE to Release
        uses: softprops/action-gh-release@v2
        with:
          files: dist/资金统计软件.exe
```

### 触发打包

```bash
# 打 tag 触发 Actions
git tag v2.1.0
git push origin v2.1.0
```

打包完成后，在 GitHub Release 页面下载 `资金统计软件.exe`。

### Windows 实机验证

- 将 EXE 复制到 Windows 电脑，确保旁边有：
  - `input/`（银行流水目录）
  - `rules/规则库.xlsx`
  - `output/`（空目录，程序会自动创建）
  - `assets/logo.png`
- 双击 EXE，验证完整流程

## 阶段四：长期维护指南

### 新增银行支持

目前各银行的解析逻辑在 `src/_核心库.py` 中通过文件名关键词区分。
新增银行步骤：

1. 确认银行流水的 Excel 格式（列名、日期格式）
2. 在 `_核心库.py` 中找到 `BANK_PARSERS` 或 `_detect_bank()` 函数
3. 添加新银行的列名映射
4. 在 `input/` 目录放入新银行流水，测试解析结果

### 跨年使用

- 程序支持多年份：GUI 中手动修改「年份」字段
- 输出目录建议按年份管理：`output/2026/`、`output/2027/`
- 规则库会持续累积，无需按年分割

### 规则库备份

- 建议每季度备份 `rules/规则库.xlsx`
- 命名格式：`rules/规则库_backup_YYYYMMDD.xlsx`

### 版本发布

- 修复 Bug：打 patch tag，如 `v2.1.1`
- 新功能：打 minor tag，如 `v2.2.0`
- 重大重构：打 major tag，如 `v3.0.0`
