# 玉玄道集团 · 银行流水报表系统 v2

> 多银行 × 多公司银行流水的自动化合并、分类与收支统计系统（简化重构版）

---

## 项目概览

本项目将集团旗下 13 家公司、20+ 个银行账户的原始流水文件，自动合并为统一的月度收支统计报表，并通过规则引擎实现自动分类。

| 维度 | 说明 |
|---|---|
| 覆盖公司 | 传统文化、健康管理、医疗集团、科技、利从、建筑公司等 13 家 |
| 覆盖银行 | 招商、光大、农行、平安、中行（xlsx 全自动；xls 需安装 xlrd）|
| 收入分类 | 智能匹配引擎，30+ 条规则，准确率 100% |
| 支出分类 | 精确映射 + 关键词规则两层，支持持续积累 |
| 账户余额 | 按月动态提取期初/期末余额，含完整度状态列 |
| 报表增强 | 收支综合对比 / AutoFilter+冻结行 / 完整度状态列 / Sparkline 迷你图 |

---

## 与 v1 的核心区别

| 方面 | v1（20260506） | v2（本项目） |
|---|---|---|
| 源码文件数 | 6 个 py 文件 | **3 个 py 文件** |
| 修正工作流 | 需导出独立待修正文件 | **修正 Sheet 直接嵌入报表** |
| 输出结构 | 平铺 `output/YYYYMMDD_NNN_文件名` | **`output/YYYYMMDD_NNN/` 子目录** |
| 文件状态 | 无 | **`_待完善` / `_终稿` 后缀** |
| 修正程序 | 程序二（支出）+ 程序三（收入）分开 | **修正补录.py 合一** |

## 目录结构

```
20260510_银行流水报表系统/
│
├── README.md                          # 本文件：项目说明
├── CHANGELOG.md                       # 版本变更记录
├── PRD.md                             # 产品需求文档
│
├── input/                             # 原始银行流水文件
│   ├── *.xlsx                         # 招商银行（全自动解析）
│   └── *.xls                          # 光大/农行/平安等
│
├── output/                            # ★ 输出报表（按运行日期子目录归档）
│   └── YYYYMMDD_NNN/                  # 每次运行独立子目录
│       ├── {year}年银行【支出】全年统计_终稿.xlsx    # 全部匹配时
│       ├── {year}年银行【支出】全年统计_待完善.xlsx  # 含未匹配时
│       ├── {year}年银行【收入】全年统计_终稿.xlsx
│       └── {year}年银行【收入】全年统计_待完善.xlsx
│
├── rules/                             # ★ 规则库（核心资产）
│   └── 规则库.xlsx                    # 唯一规则文件（收入+支出合并版，5个Sheet）
│
└── src/                               # 核心代码
    ├── _核心库.py                     # ★ 内部核心库（合并自 v1 三个文件，勿直接运行）
    ├── 生成报表.py                    # ★ 入口一：一键生成收支报表
    └── 修正补录.py                    # ★ 入口二：补充规则，重新生成报表
```

## 快速运行

```bash
# 第一步：生成报表
python src/生成报表.py

# 第二步（如有未匹配记录）：打开 _待完善 报表，填写黄色列，然后运行
python src/修正补录.py
```

### 常用参数

```bash
python src/生成报表.py --year 2026       # 指定年份
python src/生成报表.py --expense-only    # 仅支出报表
python src/生成报表.py --income-only     # 仅收入报表
python src/生成报表.py --no-enhance      # 跳过增强功能（快速模式）

python src/修正补录.py                              # 自动找最新 _待完善 报表
python src/修正补录.py --input output/20260510_001/2026年银行【支出】全年统计_待完善.xlsx
python src/修正补录.py --no-rerun                   # 只更新规则库，不重新生成
python src/修正补录.py --dry-run                    # 预览将写入的规则
```

## 修正补录工作流

```
1. 运行 生成报表.py
   └─ 输出 output/YYYYMMDD_NNN/
       ├─ 2026年银行【支出】全年统计_待完善.xlsx
       │    └─ Sheet "★支出未匹配（可补规则）"  ← 黄色列待填
       └─ 2026年银行【收入】全年统计_待完善.xlsx
            └─ Sheet "★收入未匹配（可补规则）"  ← 黄色列待填

2. 财务人员在黄色列填写【修正费用类型】/【修正收入类型】/【修正承担部门】
   ⚠️  不要修改或删除【_映射键】列

3. 保存并关闭 Excel

4. 运行 修正补录.py
   └─ 自动读取修正 → 写入 rules/规则库.xlsx → 重新生成报表
   └─ 新输出到 output/YYYYMMDD_NNN+1/
       ├─ 2026年银行【支出】全年统计_终稿.xlsx   ← 全部匹配后变为终稿
       └─ 2026年银行【收入】全年统计_终稿.xlsx
```

## 输出报表结构

### 支出报表 Sheet 说明

| Sheet | 内容 | 单位 |
|---|---|---|
| **各账户余额** | 22账户按公司分组，含月度期初/期末余额 + 完整度状态列 | 元 |
| 全年总览 | 统计摘要 + 月度汇总 | 万元 |
| 公司月度汇总 | 各公司每月支出矩阵 | 万元 |
| 费用类型汇总 | 47种费用类型 × 月份 | 万元 |
| 承担部门汇总 | 各部门 × 月份 | 万元 |
| M月汇总 | 公司 × 费用类型 | 元 |
| **M月明细** | 全部流水 + AutoFilter + 冻结行 | 元 |
| **★支出未匹配（可补规则）** | 未匹配记录，黄色列待填（_待完善时有此 Sheet） | 元 |

### 收入报表 Sheet 说明

| Sheet | 内容 | 单位 |
|---|---|---|
| **各账户余额** | 同支出报表，含完整度状态列 | 元 |
| **收支综合对比** | 全集团月度净现金流 + 各公司对比，含 AutoFilter | 元 |
| 全年总览（收入）| 统计摘要 + 月度汇总 | 万元 |
| **公司月度汇总（收入）** | 各公司每月收入矩阵 + Sparkline 趋势图 | 万元 |
| 收入类型汇总 / 来源公司汇总 | 多维分类汇总 | 万元 |
| **M月收入明细** | 全部流水，含 AutoFilter + 颜色区分 | 元 |
| 收入匹配汇总 | 按收入类型/公司的笔数、金额、占比 | 元 |
| **★收入未匹配（可补规则）** | 未匹配记录，黄色列待填（_待完善时有此 Sheet） | 元 |

## 依赖安装

```bash
pip install openpyxl xlrd
```

> `xlrd` 仅在读取 `.xls` 格式文件（光大/农行/平安等）时需要。
> 若只处理招商银行 `.xlsx` 文件，可不安装 xlrd。
